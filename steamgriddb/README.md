# Optional StreamLight artwork for Steam

These PNGs can be assigned manually to a non-Steam StreamLight shortcut. They are optional and are not used by the application itself.

- `streamlight-cover.png`: vertical library cover (1024 × 1536).
- `streamlight-wide.png`: wide tile (1834 × 857).
- `streamlight-bgnd.png`: library background / hero (2206 × 713).
- `streamlight-logo.png`: library logo (2172 × 724).
- `streamlight-icon.png`: shortcut icon where PNG is supported (672 × 672).

Download the original PNGs and use Steam's custom artwork controls to assign the images you want. The folder name does not require a SteamGridDB account or imply that the images are downloaded from that service. Keeping the default Steam artwork is fine.
